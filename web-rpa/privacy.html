Kebijakan Privasi Web RPA

Berlaku sejak 28 Oktober 2026

Data yang diakses

  • Web RPA meminta izin Google Drive hanya untuk mengunggah file laporan ke folder Google Drive milik pemilik aplikasi, dan mencari file dengan nama yang sama agar bisa disimpan sebagai versi baru.
  • Web RPA tidak membaca, mengubah, atau menghapus file lain di Google Drive.
  • Data Google (token izin) disimpan hanya di server milik pemilik aplikasi.

Penggunaan dan pembagian data

  • Data hanya dipakai untuk keperluan internal pemilik aplikasi.
  • Data tidak dijual, tidak dibagikan kepada pihak ketiga, dan tidak dipakai untuk iklan.
  • Aplikasi ini tidak tersedia untuk umum.

Mencabut izin

Izin dapat dicabut kapan saja di myaccount.google.com/permissions.

English summary

Web RPA uses Google Drive access only to upload report files to the owner's own Drive folders (and to find files with the same name so they are saved as a new version). It does not read, modify or delete other files. Data is used internally only, is never sold or shared with third parties, and access can be revoked at any time at myaccount.google.com/permissions.
